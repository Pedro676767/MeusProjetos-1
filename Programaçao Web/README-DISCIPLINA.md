# 💻 Programação Orientada a Objetos (C#)

Bem-vindo ao diretório da disciplina de Programação Orientada a Objetos! Aqui estão centralizados todos os algoritmos, listas de exercícios e o projeto prático desenvolvidos ao longo das aulas.

## 🎯 Objetivo da Disciplina
Compreender e aplicar os pilares da Orientação a Objetos (Encapsulamento, Herança, Abstração e Polimorfismo) utilizando a linguagem C# e o ecossistema .NET.

## 🗂️ Organização desta Pasta

* **`/Materiais`**: Contém resumos teóricos, anotações de aula e diagramas de classe (UML).
* **`/Projetos`**: Contém o código-fonte dos laboratórios e do projeto integrador.
